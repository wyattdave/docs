# Code Block

Code Block extracts all Power FX code into one page.  The code is organised by Screen, then Component, then Parameter

Each parameter is shown under a section title that shows:

* Component Name
* Component Type
* Screen Name

The parameter will then be highlighted in bold with the code shown below it.



By default only "On" parameters are included, as generic parameters like X/Y or Font would add possibly unnecessary code to review.

To add all parameters, uncheck the 'Code Block only 'On' parameters in the settings before importing the solution.



<figure><img src=".gitbook/assets/image (44).png" alt=""><figcaption></figcaption></figure>





Once load the key words can be searched for within the code block, Enter the word to search and click the search icon.

<figure><img src=".gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure>

Number of matches will be shown and the match will be highlighted in dark purple. Additional matches will be highlighted in light purple, and can be found by clicking Next/Previous.
