# Create Custom Flag

To create a custom flag click the settings cog in the bottom left of the screen and select Custom Flags.

<figure><img src="../../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

All of your custom flags will be listed, out of the box 6 custom flags are included, these can be deleted if you do not wish to use them.

To add a new custom flag click the Add Custom Flag button:

<figure><img src="../../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>

This will add a new flag card at the bottom of the page with a basic flag included to be edited.

Add name and custom code, you can validate the code you have added is valid by clicking the relevant Validate Code button.

Once ready click the Save Custom Flags button, if you create, modify, delete, any custom flags, the update will not be confirmed until you click the Save Custom Flags button (aka if you make a mistake refresh the page and the custom flags from last save will appear).&#x20;
