# Flag Report

Flags are used automated testing to highlight issues. They are 2 different types of flags, Solution and Custom.

Solution Flags are generated by Power Apps, are included in the solution, and are based on App checker in the studio.

Custom Flags are checks that you create against the generated data from AppReview-Pro.



Flags are only shown if they do not pass (so they wont appear as a pass, they just wont appear in the list)



There are the following information in each flag:

* Name
* Level
* How to Fix
* Why it Failed
* Type of Flag
* Impact Category

### Type

Covers what part of the app is impacted:

* App&#x20;
* Solution
* Connections
* Any Custom You Create



### Impact Category

Based on the built in App Checker in Power Apps Studio, this covers:

* Formulas
* Runtime
* Accessibility
* Performance
* Data Source
* Any Custom You Create
