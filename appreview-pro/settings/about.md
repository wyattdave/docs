### License Information

* License Key - Hover to view
* Device Sign ins - Normally max 2 different devices
* Device Name -  Instance name
* Instance ID - Instance id for this device
* Instance Created at - DateTime first logged into this device
* Lemon Squeezy ID - Your Lemo Squeezy account id, can be used through contact us (FAQ's) to cancel subscription if forgort email address
* Owner Email - Email address linked to License Key, required to cancel subscription standard way

### Remove License Key From This Device

When changing device you are required to unlink from the old device, this frees up one of your two instances.  This can also be done through [https://app.lemonsqueezy.com/my-orders/](https://app.lemonsqueezy.com/my-orders/), see FAQ's for more details.

### Bug Report

AppReview-Pro will automatically ask for a bug report when it experiences a system issue. You have the option to include system logs, these generally include data from your export. Please to do not send logs if you have sensitive data within your export, but if you don't sending this data will help fix the issue. The export data is only ever stored for maximum of 28 days.

You can also raise a bug here in the About page.
