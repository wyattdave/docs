# Info

Info shows key information about you app/solution

### Scorecards

<figure><img src="../.gitbook/assets/image (29).png" alt=""><figcaption></figcaption></figure>

Top 4 cards so KPI data about your app.

* Screens: Green <8, Amber 8-10, Red >10
* Components: Green <500, Amber 500-999, Red >999
* Variables:  Green <80, Amber 80-99, Red >99
* Connections: Green <4, Amber 4-5, Red >5



### App Information



**Name**: App Name

**ID**: App ID

**Type**: Mobile/DesktopOrTablet

**Description**: App description

**Api Limit:** Item limit for SharePoint and Dataverse

**Error Count**: App Checker Flags

**Instrument Key:** App Insights key

**Originating Version:** Version

**PCF:** Includes Power Apps Component Framework

### Experimental

All non standard options enabled in your app (example enableonstart which enables the legacy OnStart code run when the app loads).

These options although non standard are still sometimes on by default.

<figure><img src="../.gitbook/assets/image (32).png" alt=""><figcaption></figcaption></figure>

Component totals shows count of each component type used. Any component which shows a guid instead of a standard description represents a custom component.
