# Account

Flow Utilizer stores all solutions locally, but for certain use cases you may wish to export/import all solutions.

* Move Device
* Track multiple accounts (e.g Service Accounts)
* Back-up
* Import into different system

To Export your account click the Account option in the menu. A Pop up should appear showing a input box for the account name and a button to download.

<figure><img src="../../.gitbook/assets/image (27).png" alt="" width="563"><figcaption></figcaption></figure>

Accounts can be imported from the same popup.

The download file is a YAML file and follows a matching schema to the solution.
