# Charts

<figure><img src="../.gitbook/assets/image (260).png" alt="" width="563"><figcaption></figcaption></figure>

The Charts tab provides key information from all of your solutions. Currently there are 4 charts available, with more planned soon.

{% hint style="info" %}
If you have any ideas for useful charts please contact us through [powerdevbox.com/contact.html](https://powerdevbox.com/contact.html)
{% endhint %}

### Calls By Solution By Day

This chart shows all solutions and the total daily calls they make per day. A Solution can be toggled off by clicking it in the key.

<figure><img src="../.gitbook/assets/image (21).png" alt="" width="563"><figcaption></figcaption></figure>

### Calls By Day

Shows the distribution of calls per day of the week. Hovering will show the exact total calls for that day

<figure><img src="../.gitbook/assets/image (25).png" alt="" width="407"><figcaption></figcaption></figure>

### Flows By Solution

Shows a count of flows per solution. Hovering over the area will show the name and number of flows

<figure><img src="../.gitbook/assets/image (24).png" alt="" width="430"><figcaption></figcaption></figure>

### Top 10 Flows By Run Calls

Shows the top 10 flows with the most Calls per run, this does not include how many times per day they run. Hovering shows the exact daily calls the flow uses.

<figure><img src="../.gitbook/assets/image (26).png" alt="" width="563"><figcaption></figcaption></figure>
