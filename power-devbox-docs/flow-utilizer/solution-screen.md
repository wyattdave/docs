# Solution Screen

The Solution screen shows all saved solutions locally in your browser. The screen is spliit into 2 sections, Left Pane and Right Pane.

<figure><img src="../.gitbook/assets/image (250).png" alt="" width="563"><figcaption></figcaption></figure>

### Left Pane

The Left Pane has 2 cards:

* Total Calls
* Solutions

#### Total Calls

The Total calls shows Max Daily Calls and the count of flows. If the Flow table from the Right Pane is filtered then these numbers will update.

In the top right one of 2 icons will show if additional licenses are need

![](<../.gitbook/assets/premium-32 (1).png>) Premium License - Over 6k and upto 40k Calls

![](<../.gitbook/assets/image (259).png>)Flow Only License - Over 40k and up to 250k Calls

#### Solutions

The solutions card lists all solutions with key information about each. You can also filter the Flow table to the specific solution.

<figure><img src="../.gitbook/assets/image (251).png" alt="" width="563"><figcaption></figcaption></figure>

A solution can also be deleted by clicking the trash can.



Additionally there is a import icon at the top, this is where you import the download YAML files.

<figure><img src="../.gitbook/assets/image (252).png" alt="" width="563"><figcaption></figcaption></figure>

### Right Pane

The right pane is a table of all the flows in all solutions.

<figure><img src="../.gitbook/assets/image (253).png" alt="" width="563"><figcaption></figcaption></figure>

Above the table you have 2 icons, Clear Filter and Filter By Date.

Filter By Date will only show flows that run on selected days of the week.

<figure><img src="../.gitbook/assets/image (254).png" alt="" width="246"><figcaption></figcaption></figure>

In the flow table you are able to see key information and select each flow and remove from the totals.

<figure><img src="../.gitbook/assets/image (255).png" alt="" width="563"><figcaption></figcaption></figure>
