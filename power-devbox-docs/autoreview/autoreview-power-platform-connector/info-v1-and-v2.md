# Info  (v1 & v2)

***

### Info

<figure><img src="../../.gitbook/assets/image (162).png" alt="" width="563"><figcaption></figcaption></figure>

Provides latest updates and version information about the connector.

<figure><img src="../../.gitbook/assets/image (164).png" alt="" width="557"><figcaption></figcaption></figure>



* Version - current version, see [https://powerdevbox.com/autoreview%20log.html](https://powerdevbox.com/autoreview%20log.html) for change log
* Next version - date new version is planned for release
* apiKey - information about your apiKey, including expirary
* Messages - any messages/updates and when they were added
