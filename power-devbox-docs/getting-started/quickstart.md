# Install Chromium Extensions

Power DevBox Extensions currently only support Chromium based browsers, examples include:

Google Chrome&#x20;

* Google Chrome
* &#x20;Microsoft Edge
* Brave
* Opera&#x20;
* Vivaldi
* Epic Privacy Browser
* Blisk
* Ungoogled Chromium
* Kiwi Browser

Currently only 2 extension stores provide the Power DevBox extensions, Chrome and Edge, though any of the above browsers can use the stores.

Search for 'Power DevBox', select the required extension and click install

<figure><img src="../.gitbook/assets/image (184).png" alt=""><figcaption><p>Edge</p></figcaption></figure>
