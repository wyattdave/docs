# Code Block

<figure><img src="../../.gitbook/assets/image (271).png" alt="" width="563"><figcaption></figcaption></figure>

The Code Block brings all code in the app into one page. Due to the size of some apps the performance of AppReview can be effected, to rectify this before importing the solution you can select only to return on parameters

* OnSelect
* OnChange

<figure><img src="../../.gitbook/assets/image (272).png" alt="" width="392"><figcaption></figcaption></figure>

### Components

Each component is highlight by a grey header strip, this shows the Component Name - Type / Screen

<figure><img src="../../.gitbook/assets/image (273).png" alt="" width="458"><figcaption></figcaption></figure>

### Search

The Code Block can be searched by key word by entering the search string in the search box.

<figure><img src="../../.gitbook/assets/image (274).png" alt="" width="563"><figcaption></figcaption></figure>

A popup will appear in the top right corner which shows count found of search string and buttons to go to next/previous find.
