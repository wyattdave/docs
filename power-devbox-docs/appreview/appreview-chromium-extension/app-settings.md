# App Settings

<figure><img src="../../.gitbook/assets/image (42).png" alt="" width="563"><figcaption></figcaption></figure>

The App settings shows key information about the App.

### &#x20;Key Cards

4 top cards show the following key information

* Number of Screens
* Number of Components
* Number of Variabls
* Number of Connections

## App Information

Information about the App:

* ID (app id)
* Type (DesktopOrTablet, Mobile)
* Description (Description of app)
* Api Limit (Get Items max return)
* Error Count (App Checker count of errors)
* Instrument Key (For App Insights)<br>

### Experimental

Any preview settings enabled

List of all screens
