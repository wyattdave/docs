# New UI Clipboard

### Add to Clipboard

To add to clipboard first copy the required action.

<figure><img src="../../../.gitbook/assets/image (208).png" alt=""><figcaption></figcaption></figure>

Then Click the 'Add to Clipboard' menu option. A popup should open, enter the name to be stored in the clipboard and save.

<figure><img src="../../../.gitbook/assets/image (210).png" alt="" width="423"><figcaption></figcaption></figure>

### Add to Flow

To add to your flow click the actions name in the list.

The action/container has now been set ready to add. You should see all of the plus icons turn red (<img src="../../../.gitbook/assets/image (113).png" alt="" data-size="line"> ) to indicator this.

<figure><img src="../../../.gitbook/assets/image (109).png" alt=""><figcaption></figcaption></figure>

Click the plus icon to add the action where required.

The clipboard action will time out after 10 seconds and all of the icons will turn back to white.

### Delete

To delete a saved action/container from the clipboard click the trach <img src="../../../.gitbook/assets/image (98).png" alt="" data-size="line">can next to the action name.

### Export

Clipboard items can be exported and then imported into other Power DevBox Utility versions. Click the export icon <img src="../../../.gitbook/assets/image (97).png" alt="" data-size="line">
