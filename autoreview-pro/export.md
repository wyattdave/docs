# Export

For each tab of data it is possible to export the tab as a html file to save locally.

<figure><img src=".gitbook/assets/image (6).png" alt="" width="471"><figcaption></figcaption></figure>

Click the export icon in the top right of the tab and the html file will be exported.

The export file is styled differently and does not include functions like filtering but it is detached from AutoReview-Pro so will work without a license and internet connection.

<figure><img src=".gitbook/assets/image (7).png" alt="" width="563"><figcaption></figcaption></figure>

{% hint style="info" %}
The Diagram mode uses the icon urls stored in the Power Automate definition, so these icons may show a broken image when offline.

It is is also posssible in the future if Microsoft changes the image url these may break.
{% endhint %}
