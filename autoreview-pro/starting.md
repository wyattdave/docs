# Starting

<figure><img src=".gitbook/assets/image (5).png" alt="" width="563"><figcaption></figcaption></figure>

AutoReview requires a solution export containing Power Automate flows. To load the solution drag the file into the upload zone or click the zone to open the file explorer.

<figure><img src=".gitbook/assets/image (45).png" alt=""><figcaption></figcaption></figure>

After the solution loads the following tabs will load:

[File Tree](pages/file-tree.md)

[Solution](pages/solution.md)

[Custom Flags (if applic)](https://app.gitbook.com/s/gFHoCRdxSuUBb5loZUgY/custom-flags)



Clicking the refesh icon in the top left reloads the current solution

#### Flows

All of the flows in the solution will appear in the lower left section, clicking these flows will load the flow review in the right tab.

You can filter flows by entering text in the Filters input



#### Tabs

All data is loaded into tabs, clicking on tabs sets that tab in focus.

Right clicking the tab opens up a menu.

<figure><img src=".gitbook/assets/image (44).png" alt="" width="563"><figcaption></figcaption></figure>

Here you can Open the tab in a new window, close the tab, or close all other tabs.
