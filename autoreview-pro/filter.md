# Filter

For  most pages a filter input will appear at the top of the page.

<figure><img src=".gitbook/assets/image (3).png" alt="" width="505"><figcaption></figcaption></figure>

The filter allows tables in the page to be filtered, to use the filter the following syntax is used:

* columnName **=** value
* columnName **!=** value (not equal to)
* columnName **includes** value (in string)
* columnName **!includes** value (not n string)

To clear filter delete the input and click search



To help find the right syntax intellisense will show and using tab will auto complete.
