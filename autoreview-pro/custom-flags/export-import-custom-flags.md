# Export/Import Custom Flags

Custom flags can be exported to back up your code and to share with other AutoReview-Pro users.

<figure><img src="../.gitbook/assets/image (43).png" alt="" width="563"><figcaption></figcaption></figure>

Clicking the Export button will save the custom flags to your device.

Click the Import button and select a Export file to load the custom flags. The upload will merge the flags, so:

* New flags will be added to exsisting
* Flags duplicated in AutoReview-Pro and the Import file will be updated
* Flags in AutoRevirw-Pro but not in the Import file will remain&#x20;
