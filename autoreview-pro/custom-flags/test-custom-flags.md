# Test Custom Flags

To ensure your code is working correctly you can test you custom flag by pressing the Test button.

This will run the current flags against either a test solution, or the current solution you have loaded.

Testing does not save the flag, so please ensure you save after successfully testing.

The test will open the Custom Flag Results table and show any exceptions/errors in the solution.
