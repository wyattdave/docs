# Create Custom Flags

To create a Custom Flag click the Custom Flag option in the menu. You will then see any custom flags you have.

Click Add Flag to add a new flag code snippit.

<figure><img src="../.gitbook/assets/image (41).png" alt="" width="563"><figcaption></figcaption></figure>

Default code will be added, this needs to be changed. The flag also requires a name.

Multiple Flags can be added, please be aware that the flags are not saved until the Save button os clicked, if you close the tab your edits will be lost.

Click the Validate Code button to check that the code is valid JavaScript.



Click Delete to delete the custom flag.
